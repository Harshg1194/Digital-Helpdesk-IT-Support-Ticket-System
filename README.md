# Digital Helpdesk & IT Support Ticket System

A simple mini project built with HTML, CSS, Bootstrap 5, JavaScript, and AngularJS.

## Features
- Raise a new IT support ticket (Name, Department, Category, Priority, Title, Description)
- View total, open, in-progress, and resolved ticket counts
- Search tickets and filter by status
- Update ticket status directly from the table
- Delete tickets
- Saves data in browser `localStorage`

## Files
- `index.html` - Page layout and AngularJS bindings
- `css/style.css` - Basic custom CSS
- `js/app.js` - AngularJS module and controller

## How to Run
Open `index.html` in a web browser.
